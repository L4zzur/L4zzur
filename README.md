## Projects

### [car minder](https://github.com/L4zzur/car-minder)

A self-hosted car maintenance tracker.

It helps keep track of oil changes and repairs, monitor mileage, and never forget about upcoming maintenance.

**FastAPI · Svelte · Docker · self-hosted**

### [FastStream Cafe Bot Demo](https://github.com/L4zzur/faststream-cafe-bot)

A small demonstration project built around a microservices architecture.

It simulates a Telegram cafe bot and uses FastStream, RabbitMQ and FastAPI for communication between services.

**FastAPI · FastStream · RabbitMQ · Docker · Telegram**
